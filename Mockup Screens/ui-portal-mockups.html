📋 Rules to Consider While Uploading a File

File rules
  • Formats: .csv, .xlsx, .xls only; max size 50 MB per file (batch total 200 MB).
  • Naming convention: <family>_<region>_YYYYMM — e.g. sales_emea_202610.xlsx.
  • Encoding must be UTF-8 (CSV); Excel must be a real workbook, not renamed.
Data rules
  • Header row is mandatory and must match the registered schema for the selected data family.
  • All files in a batch must belong to the same data family.
  • Duplicate files (name + checksum) are rejected at the Volume stage.
  • Mandatory columns must not be null; rows failing checks are skipped and reported.
